Installation

Add the TypeScript, Python, Ruby, Rust, Java or .NET client to your project.

Every client is generated from the same OpenAPI contract, so they all expose the same operations with the same field names. Pick the one that matches your stack.

Note

TypeScript and Python install from npm and PyPI. Ruby, Rust, Java and .NET are published as downloadable files on the GitHub Release, so you fetch them by URL. The installation commands below assume the package names Fern generates; check the real ones in packages/sdk-<language>/ after your first generation, or in the publishing notes.

TypeScript#

bashnpm install @dsainvg/decide-extractor-sdk

bashpnpm add @dsainvg/decide-extractor-sdk
# or
yarn add @dsainvg/decide-extractor-sdk

Requires Node 18 or newer. Ships type declarations, no any in sight.

tsimport { DsainvgApiClient } from "@dsainvg/decide-extractor-sdk";

const client = new DsainvgApiClient({
  baseUrl: "http://localhost:8080",
  token: process.env.DECIDE_EXTRACTOR_TOKEN,
});

Python#

bashpip install dsainvg-decide-extractor-sdk

bashuv add dsainvg-decide-extractor-sdk

Requires Python 3.9 or newer. An async client is available alongside the synchronous one.

pythonfrom dsainvg_decide_extractor_sdk import DsainvgApi

client = DsainvgApi(
    base_url="http://localhost:8080",
    token="...",
)

Ruby#

bashgem install decide_extractor

rubyrequire "decide_extractor"

client = DsainvgApi.new(
  base_url: "http://localhost:8080",
  token: ENV.fetch("DECIDE_EXTRACTOR_TOKEN")
)

Rust#

toml# Cargo.toml
[dependencies]
decide-extractor = "0.3"

rustuse dsainvg_api::DsainvgApi;

let client = DsainvgApi::builder()
    .base_url("http://localhost:8080")
    .build()?;

Java#

Maven coordinates are com.dsainvg:dexa-sdk. The SDK is not on Maven Central, so install the jar from the release:

bashcurl -L -o dexa-sdk.jar \
  https://github.com/dsainvg/decide-extract-sdk/releases/download/v0.3.0/java-dexa-sdk-0.3.0.jar
mvn install:install-file -Dfile=dexa-sdk.jar -DgroupId=com.dsainvg -DartifactId=dexa-sdk -Dversion=0.3.0

xml<dependency>
  <groupId>com.dsainvg</groupId>
  <artifactId>dexa-sdk</artifactId>
  <version>0.3.0</version>
</dependency>

javavar client = DsainvgApiClient.builder()
    .baseUrl("http://localhost:8080")
    .token(System.getenv("DECIDE_EXTRACTOR_TOKEN"))
    .build();

.NET#

bashdotnet add package DsainvgApi

csharpusing DsainvgApi;

var client = new DsainvgApiClient(new DsainvgApiClientOptions
{
    BaseUrl = "http://localhost:8080",
    Token = Environment.GetEnvironmentVariable("DECIDE_EXTRACTOR_TOKEN"),
});

C++#

There is no generated C++ client. The API is plain JSON over HTTP, so any HTTP library works. See clients for a complete example using curl and nlohmann/json.

Working against the sources instead#

To use a client before it is published, generate it locally:

bashgit clone https://github.com/dsainvg/decide-extract-sdk.git
cd decide-extractor-sdk
npm install
npm run fern:generate     # requires Docker

Then reference the package from packages/sdk-ts or packages/sdk-py directly. Repository layout explains the rest.
